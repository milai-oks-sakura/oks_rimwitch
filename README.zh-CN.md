RimWitch 是一个猎魔人风格的《边缘世界》扩展。

> [!NOTE]
> RimWitch 正在为《边缘世界》1.7 开发中，需要 Harmony。本页描述的是这个 Mod 想要实现的体验，而不是一份已完成的功能清单。

## 猎魔人

如何成为一名猎魔人：

1. **制作药剂,使用**——通过种植草药和在制药桌制作
2. **进入设备,突变**——进入特定建筑,一段时间后突变

成为猎魔人后的好处:

1. **属性增强**
2. **掌握法印**
3. **可以使用药剂和煎药**
4. **毒性**

## 怪物入侵

- 入侵会成批出现，有时几种怪物混在一起。
- 打赢后可以回收怪物材料，用来做药剂、剑油和装备。


## 狩魔任务

- 其他势力发布任务，狩猎怪物。

## 拓展

后续更新会继续加内容：

- 更多种类的怪物，包括更强的变种。
- 更多装备、药剂和配方。
- 联动DLC内容
- 其他模组联动
