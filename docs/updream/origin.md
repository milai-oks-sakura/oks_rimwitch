# RimWorld Art Style

## 核心观念

**"RimWorld 的画面之于游戏，就像字体之于小说。"**

RimWorld 的重点是生成故事，画面是让玩家在脑中讲故事的工具，而不是展示对象。
因此图形是**抽象化的图标**，不是写实插画。判断一切取舍的总原则：

> 用最少的投入，换最大的收益（do that which brings the most benefit for the least amount of effort）。

细节不是价值，能被读懂的细节才是价值。多加一笔只有在"丰富故事"时才成立，否则就是噪音。
必要时保留模糊空间——收纳架的哪一面朝上、镰刀机（Scyther）的形体究竟如何，玩家自己会补完，甚至由此产生同人创作。

## 五条风格标准

1. **不丑（Not ugly）**
   至少达到"看着不难受"的审美底线。丑陋或看着痛苦的画面会直接劝退玩家。

2. **易识别（Easily identifiable）**
   一眼能看出它是什么、正在发生什么。可识别性优先于美观。

3. **低噪音（Minimal noise）**
   简化形体、减少高频细节，降低读图认知负荷。一屏可能同时存在上百个物体，
   满屏细节会让"什么重要"变得难以扫描。

4. **强度层级（Intensity hierarchy）**
   用视觉强度排出主次：与故事相关的要抓眼，次要的应让视线滑过去。
   层级**主要由描边建立**（见下表），不是靠细节量。

5. **快速实现 + 留白（Fast implementation / room for interpretation）**
   砍细节、扩内容。只保留推动故事所需的细节，其余全部删掉；
   形体上留出可被玩家自由解读的余地。

## 描边与强度层级（硬性规则）

| 类别 | 描边 | 效果 |
|---|---|---|
| 角色（Pawn） | 2–3 px 纯黑，最粗 | 全场最跳，视线第一落点 |
| 物品 / 建筑 / 墙 | 2–3 px 黑实线 | 明确、干净、可辨识 |
| 植物 | 深绿色描边，或无描边 | 微微融入背景；成片树林会"糊"在一起，让角色凸显 |

要点：**层级差靠描边粗细与颜色拉开**，同一画面里不要给所有东西一样的描边。

## 制作规范

- **画布**：用正方形画布。游戏会把物品贴图缩放到 64×64，因此在 **128×128** 上作画最舒适。
  画布越大、或像素画得越小 → 物品在游戏里显得越小。
- **构图偏移**：需要偏心的构图时，用**补白（padding）** 而不是移动主体。
- **底色层**：垫一层完全不透明黑、约 **1% 不透明度** 的最底层，用来压掉边缘漏出的白像素（alpha 白边）。
- **少用/不用黑色内线**：反向描边（inner line）不要用黑色画，用**明暗与色差**表达结构。
- **细节预算**：宽度小于 **3 px** 的细节基本看不见，除非有很强的颜色对比，否则不要画。
- **不追求写实，不追求炫技**：不要用亮闪闪的特效或高对比装饰把注意力从故事上引开。

## 工作流

1. 先问：这个东西在故事里承担什么？据此定它的**强度等级**（角色 / 物品 / 植物）。
2. 用最大块的色块把剪影画出来，然后眯眼检查：**只看剪影能否认出它是什么**。
3. 按等级加描边（角色与物品黑线 2–3 px，植物深绿或无线）。
4. 只用明暗/色差加结构，不加黑色内线。
5. 逐层删细节：删掉后不影响识别的，就永久删掉。
6. 缩到 64×64（或游戏内实际尺寸）复核：白边、糊边、噪点、层级是否还成立。
7. 放进场景截图里对比香草素材：它是否"属于"这个画面，而不是贴在画面上。

## 评审清单（逐条回答是/否）

- [ ] 缩到游戏尺寸后，还能认出它是什么吗？
- [ ] 剪影是否独特，不会与同类物体混淆？
- [ ] 描边粗细/颜色是否符合它的强度等级？
- [ ] 有没有宽度小于 3 px 且低对比的无效细节？
- [ ] 有没有多余的黑色内线（本应交给明暗处理）？
- [ ] 是否加了 1% 黑底，边缘无白边？
- [ ] 在一屏上百个物体中，它会不会抢走主角（Pawn）的注意力？
- [ ] 它是否在替玩家把故事"讲完"，而不是留下想象空间？

## 常见错误

- 把图标当插画来画：细节堆满、缩小后成一团噪点。
- 给植物画粗黑边，导致植被比角色还跳，破坏强度层级。
- 用黑色内线勾结构，画面变脏、变"贴纸感"。
- 用超大画布或过小像素，导致物品在游戏里比例失衡。
- 用发光、强渐变、锐利高光吸引视线，把注意力从叙事上引开。
